== INV : F = (A)'
   n-network: ('nmos', 'A')
   p-network: ('pmos', 'A')
   transistors: 1 nMOS + 1 pMOS = 2
   all 2 inputs: exactly one network conducts and output = F -> True
== NAND2: F = (A·B)'

   transistors: 2 nMOS + 2 pMOS = 4
   all 4 inputs: exactly one network conducts and output = F -> True
