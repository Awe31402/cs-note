## 2. 電晶體就是開關

[03:18] 電路最基本的元素，像原子和分子：**電晶體（transistor）**。

[03:42] 用一般人的話說，它就是一個**開關**，跟電燈開關一樣：

| 開關 | 電流 |
|---|---|
| 打開（off） | 不流，像斷路（open circuit） |
| 關上（on） | 從一端流到另一端 |

## 3. 矽與 doping

[04:26] 過去 40–50 年，電晶體都是用**矽（silicon）**做的。矽是沙子的基本元素，褐灰色。

[04:45] 矽是**半導體**：不是導體、也不是絕緣體，介於中間。神奇的是可以改變它的性質：加一點雜質，叫 **doping（摻雜）**。

| 摻什麼 | 例子 | 結果 | 多出來的載子 |
|---|---|---|---|
| **第 3 族**元素（最外層 3 個電子） | 硼（B）、鋁、鎵 | **p-type** 半導體 | 電洞（hole） |
| **第 5 族**元素（最外層 5 個電子） | 磷（P）、砷 | **n-type** 半導體 | 電子 |

[06:31] 矽是第 4 族，最外層 4 個電子。每個矽原子和 4 個鄰居形成**共價鍵**，4 + 4 = 8，很穩定，排成晶格（投影片是 3D 晶格的 2D 示意）。

[13:29] 摻了第 3 族或第 5 族，就多了**電荷載子**（電洞或電子），所以導電性上升。

---

## 4. 電洞（hole）

[07:00] 把一個矽原子換成**硼**：硼只有 3 個電子，少一個 → 晶格裡出現一個 **hole（電洞）**，也就是「少了一個電子」。

[08:24] 電洞可以「流動」：旁邊的電子跑過來填它，電洞就換到那個電子原本的位置。

[08:50] 【口頭】為什麼電子能跑？金屬導電很好，是因為電子形成「電子氣」或「電子雲」，雖然屬於原子，但可以移動。

[09:15] 電子往一個方向補洞，就可以想成電洞往**反方向**流。電洞不是真的粒子，只是「沒有電子」，但可以把它想成帶**正電**的載子。

[10:08] 例：加一個很強的負電壓，會把電子推開 → 電洞往**負極**移動（等於電子往反方向）。

[11:29] 反過來，摻**磷**：磷有 5 個電子，和鄰居成鍵後**多一個電子**，這個電子可以移動、帶負電，在電場下從負端流向正端。

【口頭】[09:44] 修過元件物理（device physics）的話，會算電洞的等效質量等等；概觀不需要。

## 5. NMOS 電晶體

[13:50] 在 **p-type 基板（substrate）** 裡做兩個 **n-type 區域**：

```
        Source        Gate         Drain
          │      ┌──────────┐       │
          │      │polysilicon│       │
          │      │  SiO₂（很薄）│       │
     ┌────┴───┐  └──────────┘  ┌────┴───┐
     │   n    │   ← channel →  │   n    │
     └────────┘                └────────┘
                 p-type substrate
```

- [15:23] 三個端點：**drain（汲極）**、**source（源極）**、**gate（閘極）**。電流從 drain 流到 source。
- [15:44] Gate 有兩層：
  - **SiO₂（二氧化矽）**：就是沙子，**絕緣體**，非常薄（奈米等級）。
  - 上面是 **polysilicon**，透過一個小金屬接點接到 gate 的銅線。
- [17:12] 叫 NMOS 是因為有兩個 n-type 區域（也叫 n-type well）在 p-type 基板裡。

[17:28] 怎麼運作：

1. 在 gate 加**正電壓**。
2. 電子被吸過來，電洞被推開。
3. 兩個 n 區域之間形成一層導電的 **channel（通道）**。
4. 電流可以從 drain 經過 channel 流到 source。

[18:15] gate 是 0 V 就不會形成 channel，電晶體是**斷開**的開關。

[18:36] **Threshold voltage（臨界電壓）**：gate 對 source 的電壓超過它，channel 才會形成。

[19:18] 符號裡 gate 跟 drain、source **沒有連在一起**，它只控制電流。

| NMOS 的 gate | 狀態 |
|---|---|
| 正電壓（邏輯 1） | **導通** |
| 0 或負電壓（邏輯 0） | 不導通 |

【課本補充】課本 §7.1.2（p.266）講了 **P-N junction**，影片沒講。

## 6. PMOS 電晶體

[20:16] 反過來：**n-type 基板**裡做兩個 **p-type 區域**，運作也完全相反。

- [20:16] 照慣例，PMOS 的電流是從 **source 流到 drain**（只是慣例，元件本身是對稱的）。
- [20:39] gate 是 0 或負電壓 → 電洞往 channel 那邊跑 → 形成 channel → 導通。
- [21:12] 符號跟 NMOS 一樣，只是 gate 上多一個**小圓圈**。

| PMOS 的 gate | 狀態 |
|---|---|
| 正電壓（邏輯 1） | 不導通 |
| 0 或負電壓（邏輯 0） | **導通** |

## 7. CMOS 反相器

[21:56] 「沒有用上的知識有什麼用？」用電晶體做一個**反相器（inverter）**：輸入 0 → 輸出 1，輸入 1 → 輸出 0。

[22:17] 邏輯 0 實體上可能是 0 V；邏輯 1 可能是 1 V、2 V 或 3 V，不重要。

[22:47] 電路：

```
      VCC
       │
     ┤ T2（PMOS）
  A ─┤      ├── out
     ┤ T1（NMOS）
       │
      GND
```

| A | T1（NMOS） | T2（PMOS） | out 接到 | 輸出 |
|---|---|---|---|---|
| 1 | 導通 | 斷 | GND | **0** |
| 0 | 斷 | 導通 | VCC | **1** |

[24:18] 同時用 NMOS 和 PMOS，所以叫 **CMOS**（complementary MOS）。重點：

- NMOS 和 PMOS **串在一起**，NMOS 那端接 GND、PMOS 那端接 VCC。
- 分析方法：把每一種輸入列出來，看哪些電晶體開、哪些關，輸出就是接到 VCC（1）或 GND（0）。

## 8. NOR 閘

[25:02] NOR = NOT(A OR B)：只有 00 時是 1，其他都是 0。4 個電晶體：

- T1、T2（**NMOS**）：**並聯**，接在 out 和 GND 之間。
- T3、T4（**PMOS**）：**串聯**，接在 VCC 和 out 之間。
- A 接 T1、T3；B 接 T2、T4。

| A | B | T1 | T2 | T3 | T4 | 輸出 |
|---|---|---|---|---|---|---|
| 0 | 0 | 斷 | 斷 | 通 | 通 | **1**（經 T3、T4 接到 VCC） |
| 1 | 0 | 通 | 斷 | 斷 | 通 | **0**（經 T1 接到 GND） |
| 0 | 1 | 斷 | 通 | 通 | 斷 | **0**（經 T2 接到 GND） |
| 1 | 1 | 通 | 通 | 斷 | 斷 | **0** |

[27:50] 關鍵：**串聯的電晶體只要有一個斷，整條就斷**；並聯的只要一個通，整條就通。

[29:51] 符號：OR 閘加一個小圓圈，圓圈代表反相。

---

## 9. NAND 閘

[30:10] NAND = NOT(A AND B)：只有 11 時是 0。結構跟 NOR **剛好相反**：

- T1、T2（**NMOS**）：**串聯**。
- T3、T4（**PMOS**）：**並聯**。

| A | B | NMOS（串聯） | PMOS（並聯） | 輸出 |
|---|---|---|---|---|
| 0 | 0 | 斷 | 兩個都通 | **1** |
| 1 | 0 | T2 斷 → 整條斷 | T4 通 | **1** |
| 0 | 1 | T1 斷 → 整條斷 | T3 通 | **1** |
| 1 | 1 | 兩個都通 → 接 GND | 兩個都斷 | **0** |

[34:06] 總結規則：

| 閘 | NMOS | PMOS |
|---|---|---|
| NOR | 並聯 | 串聯 |
| NAND | 串聯 | 並聯 |

（本機實測：照影片接都對；故意兩個都並聯會短路、兩個都串聯會浮接。見 [§17.1](#171-cmos-閘的開關模擬)。）

## 10. 基本邏輯閘總整理

[35:11] 從電晶體一路做上來：

| 閘 | 怎麼做 |
|---|---|
| 反相器（NOT） | 1 個 PMOS ＋ 1 個 NMOS |
| NAND | 4 個電晶體 |
| NOR | 4 個電晶體 |
| AND | NAND ＋ 反相器 |
| OR | NOR ＋ 反相器 |

- [35:43] NAND 和 NOR 是 **universal gate**：只用 NAND（或只用 NOR）就能做出任何邏輯函數。為什麼，老師說有點難，先記住（第 3 支 [§16.1](lecture03_note.md#161-布林代數的規則全部驗一遍) 用 NAND 拼出了 NOT、AND、OR、XOR）。
- ⚠️ [36:10] 老師說「拿我們做好的 OR 閘，接一個反相器，就是 OR 閘」，是口誤：應該是 **NOR** 閘加反相器。
- [36:29] 符號：AND 閘的輸入那邊是**直線**，OR 閘是**曲線**，而且 OR 閘輸出端是尖的，「像箭頭」。

## 11. 組合邏輯

[37:40] **組合邏輯（combinational logic）**：用邏輯閘做出複雜的邏輯函數。

- 輸入是好幾個布林變數 a₁…aₙ，輸出可以是一個或好幾個布林變數 b₁…bₙ。
- [38:29] 對一組輸入，只有一種輸出是允許的：輸出完全由**輸入的組合**決定。
- [39:13] **沒有儲存**：這是組合邏輯和循序邏輯（下一講）的差別。

## 12. Multiplexer

[39:13] **Multiplexer（mux，多工器）**「大概是最重要的邏輯方塊」：n 個輸入，由 **select bit（選擇線）** 選一個當輸出。

- [39:34] 例：8 個輸入（編號 0–7），select = 100 就選第 4 個、select = 111 就選最後一個。
- [40:23] 第 8、9 章（課本 Ch9、Ch10）設計處理器時會看到它有多重要。

[40:59] 4 對 1 mux：兩條選擇線 A、B。

1. 產生選擇線的所有組合：Ā·B̄、Ā·B、A·B̄、A·B。**任何時候只有一個是 1**。
2. 每個組合跟對應的輸入 AND 起來。
3. 四個 AND 的輸出全部 OR 起來。

```
out = Ā·B̄·x₀₀ + Ā·B·x₀₁ + A·B̄·x₁₀ + A·B·x₁₁
```

[42:17] 為什麼對？假設 A = 1、B = 0：只有 A·B̄ = 1，那個 AND 的輸出就是 x₁₀；其他 AND 都是 0。OR 起來：x₁₀ + 0 + 0 + 0 = **x₁₀**。

[45:02] 符號：AND 通常用 `·`，OR 用 `+`；有時也寫 AND、OR 或 `|`，意思一樣，看上下文。

## 13. Demultiplexer

[45:58] **Demultiplexer（demux）**：反過來。**一個**輸入，讓它出現在 n 個輸出中的**一個**，其他輸出都是 0。

[46:54] 4 個輸出要 log₂4 = **2** 個 bit 來編號。一樣四個 AND，每個接一種選擇線的組合，再加上同一個輸入 x：

```
out₀₀ = Ā·B̄·x    out₀₁ = Ā·B·x    out₁₀ = A·B̄·x    out₁₁ = A·B·x
```

[47:48] 選擇線組合是 1 的那個 AND，輸出就等於 x；其他都是 0。

⚠️ [47:25] 老師把 4 個輸出編成「00、10、01、11」，說「這樣編有原因」，但沒說明；之後的說明又是照一般的順序。本筆記照一般順序寫。

## 14. Decoder

[49:49] **Decoder（解碼器）**：跟 demux 很像，但**更簡單**：

- n 個輸出，用 log₂n 個 bit 選一個，把它設成 **1**，其他都是 0。
- 跟 demux 的差別：**沒有那個輸入 x**。

[50:35] 2 對 4 decoder：A、B 兩個 bit，4 個 AND，只有一個輸出 1。

[51:06] 之後設計**記憶體陣列**時會非常有用（[第 20 支](lecture20_note.md)：用 decoder 選 word line）。

## 15. Encoder 與 priority encoder

[51:32] **Encoder（編碼器）**：也很重要，在記憶體裡很有用，特別是 **CAM**（content addressable memory，[第 20 支](lecture20_note.md)）。

[51:52] n 個輸入、假設**只有一個是 1**，輸出那個輸入的**編號**。例：輸入 0–7，第 6 個是 1 → 輸出 **110**。

[52:39] 如果好幾個是 1？要依**優先順序**選一個：**priority encoder**。有很多種，老師不講設計，請看數位邏輯課本。

[53:22] 8 對 3 encoder：輸入 b₀…b₇，輸出 bit 2、bit 1、bit 0。哪些輸入的編號在那個位置是 1，就把它們 OR 起來：

| 輸出 | 式子 | 為什麼 |
|---|---|---|
| bit 2 | b₄ + b₅ + b₆ + b₇ | 4–7 的編號是 1xx |
| bit 1 | b₂ + b₃ + b₆ + b₇ | 2、3、6、7 的編號是 x1x |
| bit 0 | b₁ + b₃ + b₅ + b₇ | 奇數的編號是 xx1 |

[56:21] 電路只有 **3 個 4 輸入的 OR 閘**。4 位元、5 位元的 encoder 需要輸入更多的 OR 閘，做法一樣：列表、寫式子、用閘實作。

[57:02] 下一講：循序邏輯和記憶體單元。

【課本補充】課本 §7.2.6（p.276–277）給了 priority encoder（**編號最大的優先**）的式子。4 對 2：

```
Y₁ = X₂ + X₃
Y₀ = X₁·X̄₂ + X₃
```

Y₀：X₃ 是 1 就一定是 1（它優先權最高）；X₁ 是 1 時不能直接決定，因為 X₂ 或 X₃ 可能也是 1。X₃ = 0 而 X₂ = 1 時要忽略 X₁，所以是 X₁·X̄₂。課本 Example 120 有 8 對 3 的版本。（本機驗證見 [§17.2](#172-組合邏輯方塊)。）

### 17.1 CMOS 閘的開關模擬

`cmos.py` 把電晶體當開關：NMOS 在 gate = 1 時導通、PMOS 在 gate = 0 時導通。對每一組輸入，看 out 能不能經過導通的電晶體走到 VCC 或 GND：

| out 接到 | 結果 |
|---|---|
| 只有 VCC | 1 |
| 只有 GND | 0 |
| 兩個都接到 | **X**（短路：VCC 直接接 GND） |
| 都沒接到 | **Z**（浮接：沒人決定輸出） |

```
NOT           （2 個電晶體）: 0→1  1→0
NOR           （4 個電晶體）: 00→1  01→0  10→0  11→0
NAND          （4 個電晶體）: 00→1  01→1  10→1  11→0
錯的（都並聯）       （4 個電晶體）: 00→1  01→X  10→X  11→0
錯的（都串聯）       （4 個電晶體）: 00→1  01→Z  10→Z  11→0
```

- 照影片接的 NOT、NOR、NAND 全對，而且輸出**永遠**是 0 或 1。
- 故意把 NMOS 和 PMOS **都並聯**：A ≠ B 時上下兩條路都通，VCC 直接短路到 GND（X）。
- 故意**都串聯**：A ≠ B 時上下都斷，輸出浮接（Z）。
- 所以 CMOS 一定是「一邊串聯、另一邊並聯」：任何輸入下，**剛好**一邊通、另一邊斷。這就是 [§9](#9-nand-閘) 那張表的原因。

### 17.2 組合邏輯方塊

`comb.py` 照影片的電路，用 AND／OR／NOT 拼出四個方塊，把所有輸入都試一遍：

```
4 對 1 mux： 16×4 種輸入全對
1 對 4 demux： 全對
2 對 4 decoder： {'00': [1, 0, 0, 0], '01': [0, 1, 0, 0], '10': [0, 0, 1, 0], '11': [0, 0, 0, 1]}
8 對 3 encoder（只有一個 1）： 全對
  輸入 b6 = 1 → [1, 1, 0] （110 = 6）
  輸入 b3、b5 同時是 1 → [1, 1, 1] （111 = 7，兩個都不是：所以要 priority encoder）
```

- 影片的例子（第 6 個 → 110）對。
- 一般的 encoder **只有在剛好一個輸入是 1 時**才對。b₃ 和 b₅ 同時是 1，OR 起來得到 7，既不是 3 也不是 5。這就是為什麼需要 priority encoder。
- 另外驗證了課本的 4 對 2 priority encoder（Y₀ = X₁·X̄₂ + X₃、Y₁ = X₂ + X₃）：15 種非全零的輸入，輸出都是「最大的那個編號」。

## 18. 一頁速查表

| 主題 | 重點 |
|---|---|
| 電晶體 | 開關；用矽做 |
| Doping | 第 3 族（B、Al、Ga）→ p-type、電洞；第 5 族（P、As）→ n-type、電子 |
| 電洞 | 少一個電子；想成帶正電、可移動 |
| NMOS | p 基板裡兩個 n 區；gate 1 導通；drain → source |
| PMOS | n 基板裡兩個 p 區；gate 0 導通；符號多一個圓圈 |
| Gate | SiO₂（很薄的絕緣層）＋ polysilicon |
| Threshold voltage | gate 對 source 超過它才有 channel |
| CMOS 反相器 | PMOS 在上（接 VCC）、NMOS 在下（接 GND） |
| NOR | NMOS 並聯、PMOS 串聯 |
| NAND | NMOS 串聯、PMOS 並聯 |
| 串聯／並聯 | 串聯一個斷就斷；並聯一個通就通 |
| AND／OR | NAND／NOR ＋ 反相器 |
| Universal | NAND、NOR |
| 組合邏輯 | 輸出只看輸入，沒有儲存 |
| Mux | 選擇線所有組合各 AND 一個輸入，再 OR |
| Demux | 一個輸入送到選中的輸出 |
| Decoder | 選中的輸出設 1；記憶體陣列會用 |
| Encoder | 只有一個 1 時輸出它的編號；CAM 會用 |
| Priority encoder | 很多個 1 時選優先權最高的；Y₀ = X₁·X̄₂ + X₃ |
| XOR | A·B̄ + Ā·B |
| 實測 | 開關模擬證實「一邊串、一邊並」；都並聯 → 短路、都串聯 → 浮接；mux／demux／decoder／encoder 全對 |

## 附：本講一句話總結

> **電晶體就是開關：在矽裡摻第 3 族元素（硼）得到有電洞的 p-type、摻第 5 族元素（磷）得到多電子的 n-type，p 基板裡做兩個 n 區、上面蓋一層很薄的 SiO₂ 和 polysilicon 當 gate，就是 gate 加正電壓才導通的 NMOS，反過來就是 gate 為 0 才導通的 PMOS；PMOS 接 VCC、NMOS 接 GND 串起來是 CMOS 反相器，NMOS 並聯加 PMOS 串聯是 NOR、NMOS 串聯加 PMOS 並聯是 NAND（兩者都是 universal），再加反相器就有 AND、OR；組合邏輯的輸出只看輸入、沒有儲存，最重要的是 multiplexer（選擇線的每種組合 AND 一個輸入再 OR 起來），另外還有 demultiplexer、decoder（之後選記憶體列要用）和 encoder（只有一個輸入是 1 時輸出它的編號，多個 1 時要用 priority encoder）。本機用開關模擬驗證：CMOS 一定要一邊串聯、一邊並聯，否則不是短路就是浮接。**
